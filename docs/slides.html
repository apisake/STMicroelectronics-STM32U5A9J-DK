Alarm A · นาฬิกาปลุก

ปลุกทุกวัน ขึ้นหน้าจอสีแดง "ถึงเวลาแล้ว!" ปลุกบอร์ดจาก Stop 2 ได้ และจำค่าไว้ใน backup register

Alarm B · ตีบอกเวลา

ทุก HH:00:00 ขอบจอกระพริบ 10 วินาที และ LED3 กระพริบตาม (บอร์ดไม่มีลำโพง)

บั๊ก 1 · เวลาย้อนหลังรีเซ็ต

หลังรีเซ็ต HAL_RTC_Init() ข้ามขั้นตอนเริ่มต้นเมื่อปฏิทินถูกตั้งไว้แล้ว และยังไม่ได้รอ flag RSF
แก้: เรียก HAL_RTC_WaitForSynchro() ก่อนอ่านเวลาครั้งแรก

บั๊ก 2 · ช้าลง 30 วินาทีทุกครั้งที่แฟลช

โค้ดตั้งเวลาจาก build ทุกครั้งที่ RTC ช้ากว่าเวลาที่ build แต่การ build และแฟลชใช้เวลาประมาณ 30 วินาที
แก้: ตั้งใหม่จากเวลาที่ build ก็ต่อเมื่อ RTC ช้าเกิน 10 นาที

ภาคผนวก A1 · Finite State Machine

ระบบ: บูต · ทำงาน · หลับ

อธิบายโดยสังเขป

  • บูตเสร็จเข้าสู่ Running ซึ่งเป็นลูปหลักที่วาดจอ ~30 fps
  • กดปุ่ม USER (หรือไม่แตะจอ 60 s เมื่อ ALWAYS_ON = 0) → Sleep = Stop 2 จอดับ แต่ RTC ยังเดิน
  • ตื่นได้จากแตะจอ (EXTI8), ปุ่ม (EXTI13) หรือ Alarm A/B → Waking เริ่มสัญญาณนาฬิกาและจอใหม่
  • ถ้า UART หรือจอเริ่มทำงานไม่สำเร็จ → Fault (Error_Handler)

  • รีเซ็ตตอน Paused → กลับ Idle; รีเซ็ตตอน Running → นับใหม่จาก 0 ต่อทันที
  • ระหว่าง Running บอร์ดจะไม่หลับ
